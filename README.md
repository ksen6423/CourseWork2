# Проект "Live flight tracker"

## Описание
Проект "Live flight tracker" - это программа, которая собирает данные о самолетах в воздушных пространствах тех стран, которые вы выберете.

## Установка

1. Клонируйте репозиторий
git clone https://github.com/ksen6423/CourseWork2
2. Установите зависимости
pip install -r requirements.txt


## Использование

1. Созданы классы для работы с API для получения информации о самолетах
2. Реализованы методы сравнения самолетов между собой по скорости
3. Создан класс для работы с файлами
4. Реализована функция для работы с пользователем


## Тестирование

Запуск тестов с помощью pytest (установка pip install pytest):
1. python -m pytest (все тесты в проекте)
2. python -m pytest/test_aeroplane.py (конкретный файл)

Запуск тестов с помощью unittest (встроенный фреймворк)
1. import unittest
2. python -m unittest discover (выполнение всех тестов в проекте)
